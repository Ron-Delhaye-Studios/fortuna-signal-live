## Definition
RedStone is a modular blockchain oracle network that delivers price and data feeds to DeFi protocols across 70+ chains, using a gas-efficient design that keeps data offchain and serves it on demand.

## What the holder owns (FORA-01 Q1)
RED is the operational token of RedStone's modular oracle network: it secures data delivery through staking (including the EigenLayer restaking AVS integration) and enables technical interactions in the oracle framework. It explicitly does not represent ownership, governance, or profit-sharing rights.
