## Definition
SKALE is a network of independent EVM-compatible layer-1 shards (SKALE Chains) with pooled validator security and Ethereum anchoring. End users transact gas-free via sFUEL.

## What the holder owns (FORA-01 Q1)
SKL is the hybrid utility token of the SKALE network (gas-free modular chains on Ethereum). Its three uses: paying SKALE chain subscription fees (charged to developers), network security via validator staking, and governance. It is an ERC-777 token, backward-compatible with ERC-20, with token-level delegation.
