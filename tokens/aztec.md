## Definition
Privacy-first Layer 2 on Ethereum enabling a fully programmable smart-contract environment with an encrypted state ledger, using zk-SNARKs. Designed around the Noir universal ZK language with client-side proving so sensitive data never leaves the user's device.

## What the holder owns (FORA-01 Q1)
AZTEC is the staking and governance token of Aztec, the privacy-first Ethereum L2 (Ignition chain). Sequencers and provers stake AZTEC for network security (a validator needs 200,000 AZTEC staked), holders vote in decentralized governance, and the token is used for transaction fee settlement.
