## Definition
Aleph (Aleph Cloud) is a cross-blockchain layer-2 network for decentralized applications and their infrastructure: storage, computing, and messaging. It aims to decentralize web and cloud services.

## What the holder owns (FORA-01 Q1)
ALEPH is the native token of the Aleph Cloud decentralized compute and storage network. Users pay for storage, indexing and compute services with ALEPH; node operators stake ALEPH as collateral to run Core Channel Nodes and earn ALEPH rewards; holders can delegate stake to nodes they trust. Independent research notes the network has no token-holder governance mechanism.

## Key risks & notes
The 2019 paper is explicitly a work in progress and the design has since evolved into Aleph Cloud. Early architecture centered on NULS. Decentralized-cloud competition, node availability and data-migration limits, and token-demand dependence are risks.
