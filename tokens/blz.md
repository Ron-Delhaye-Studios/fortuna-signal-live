## Definition
Bluzelle is a decentralized database protocol that provides dApps with fast, scalable data storage and retrieval via a global network of node operators.

## What the holder owns (FORA-01 Q1)
BLZ is the token powering the Bluzelle decentralized storage and database network. Documented uses are paying for transactions and storage, staking, and voting on network decisions. It is a network utility token with no documented claim on underlying assets.

## Key risks & notes
Bluzelle is an early-2018 project competing with entrenched centralized databases and other decentralized storage players (Filecoin, Arweave, IPFS-based systems). The dual-token design (BLZ/BNT or BLZ/BNT successor) adds complexity, and network utility ultimately depends on real dApp developer adoption of its database layer.
