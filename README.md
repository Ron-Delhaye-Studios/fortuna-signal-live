shareable, and measured lives here.

## Platform division (MASTER INDY decision, 2026-09-16)

| | GitHub (this repo) | Lovable |
|---|---|---|
| Role | **Canonical** — the live, shareable site | **Design sandbox** — visual experiments only |
| Content | Built static site + evidence data | Mockups, layout explorations |

**Porting rule: sandbox → human review → canonical. Never reverse.**
Nothing flows from the Lovable sandbox to the live site without human review,
and the live site is never edited just to match the sandbox. The canonical
site wins every disagreement.

## What's in this repo

- The built static site (generated by `build.py` in the private source repo —
  the build inputs are public research only; proprietary C-MGR material is never
  an input and never appears here).
- `assets/data/market-snapshot.json` — machine-refreshed market evidence.
- `assets/data/freshness.json` — stale-data flags for that evidence.
- `assets/data/tracked-assets.json` — the curated asset→CoinGecko-ID map the
  refresh reads.
- `scripts/daily_refresh.py` — the refresh script (stdlib only).
- `.github/workflows/daily-refresh.yml` — the daily automation.
- `ANALYTICS_SETUP.md` — visitor-analytics setup (3 steps).

## Daily self-update engine

`.github/workflows/daily-refresh.yml` runs every day at 07:00 America/Denver
(plus any manual run from the Actions tab):

1. `scripts/daily_refresh.py` pulls current prices from the free CoinGecko
   public API (no key, polite batching).
2. It rewrites **only the evidence layer**: `assets/data/market-snapshot.json`
   (prices, 24h change, timestamps) and `assets/data/freshness.json`
   (stale-data flags).
3. Changes are committed and pushed; GitHub Pages redeploys automatically.
   No changes → no commit.

**Hard rule: automate evidence, not judgment.** The workflow never touches
briefs, verdicts, rankings, classifications, or copy. Anything
judgment-shaped stays human-gated — always.

## Visitor analytics

Cloudflare Web Analytics (free, privacy-friendly, no cookie banner).
Setup takes ~10 minutes: see `ANALYTICS_SETUP.md`.
Until a beacon token is configured, pages render no analytics script.
